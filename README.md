## ⚙️ Running Locally

### Prerequisites
- Python 3.8 or higher installed on your system.

### Execution
To run the baseline script:
```bash
python princi.py
```
*(Press `Ctrl + C` in your terminal to terminate execution gracefully.)*

## 🛡️ Best Practices & Guidelines
- Use virtual environments (`python -m venv .venv`) when installing third-party packages.
- All temporary bytecode (`__pycache__/`) and environment files are safely excluded via `.gitignore`.
